# NöraL — Scientific Editorial website

Open `index.html` in your browser. Each menu item has its own HTML file. Styles are shared in `css/style.css` and interactions in `js/main.js`. The site supports English and Turkish.

## Before publishing
- Add official laboratory email to `contact.html` (currently deliberately blank; NO contact form).
- Complete About, research area descriptions and Facilities details; confirm planned versus available equipment.
- Verify project facts, publication citations, DOI links and personnel permissions/portraits.
- News intentionally contains no fictional announcements.
- Google Fonts requires internet; local fallbacks are configured.
- The diagram on the home page is decorative original SVG, not research data.
- Logo is typography-only because the source image `ege-noral logo.jpeg` was referenced in the workbook but not supplied as a standalone website asset.
